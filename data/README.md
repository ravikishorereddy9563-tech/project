Place the downloaded Kaggle CSV here locally if desired. Do not commit the full dataset: it is large and may contain personal information. The committed `sample_threads.csv` is the reproducible fixture used by the tests and default evaluation.

The workspace also contains `apple_threads.csv`, a prepared AppleSupport-linked extract, `golden_real.csv`, an unlabeled 200-row human-labeling template, and `support_agent.db`, the local SQLite database containing historical messages and support decisions.
